GoldSun

A Mac browser with tabs, bookmarks, downloads, and passwords saved in Keychain.

Download View Source
Native Swift UI HTTPS first Chromium engine

Privacy and connection settings

Choose HTTPS-first browsing, remove common tracking parameters from links, and manage saved passwords in macOS Keychain.

HTTPS first

HTTP navigations upgrade to HTTPS by default, with an optional strict mode for sites that should never fall back.

Tracker cleanup

Known tracking query parameters are removed before navigation, including common ad click and campaign identifiers.

Native content blocking

The WebKit development backend installs a compact rule list for common ads, trackers, and additional content in strict mode.

Keychain passwords

Saved logins use macOS Keychain storage, exact-origin autofill, native save prompts, and browser CSV import/export for migration.

Local start page

GoldSun opens to a local start page and uses Mac controls for its toolbar, tabs, and settings.

Installation

The version 0.2.20 installer includes Chromium/CEF and places GoldSun in your Applications folder.

Version 0.2.20

This prerelease includes Chromium/CEF, bookmark import and export, browsing history, downloads, and Keychain password storage. You can watch fullscreen video and open sites in your default browser when they do not allow sign-in inside GoldSun. The app checks for updates and closes before installing them. WebKit handles internal pages and builds without CEF. See the release notes for extension support. The package is unsigned, so macOS may display a first-launch security prompt.

./script/package_release.sh 0.2.20
